# 综合 Labs

`examples/` 负责隔离一个知识点，`labs/` 负责验证多个机制组合后是否仍然正确。综合项目必须同时满足：可离线运行、能观察中间状态、有失败边界、有自动测试、明确生产化差距。

| Lab | 综合主题 | 前置章节 | 状态 |
|---|---|---|---|
| [01 可恢复客服工作流](./01-support-agent/README.md) | Context、路由、子图、动态并行、checkpoint、Store、interrupt、幂等 | 01-10 | 完整参考实现 |

推荐先自己根据 `TODO.md` 设计 state 和路由，再阅读参考实现。若直接阅读实现，也应至少完成两个改造练习并补测试，否则很容易停留在“看懂”。
